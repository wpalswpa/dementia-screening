# 치매 위험 조기 스크리닝 서비스 (팀 찾아조)

웨어러블 기기(Oura ring)의 활동·수면 기록만으로 치매 위험군(경도인지장애+치매)의 신호를 걸러내, "병원에 가볼 이유가 있는지"를 먼저 알려주는 스크리닝 서비스입니다. AI Hub 치매 고위험군 라이프로그 데이터(174명)로 학습·검증했고, FastAPI 웹 서비스와 치매안심센터 안내(공공데이터포털 연동, 전국 317곳 지도 검색)까지 구현했습니다.

```text
데이터   : AI Hub 웨어러블 라이프로그 174명 (정상 111 / 경도인지장애 51 / 치매 12)
방법     : 사람마다 "평균 + 날마다의 들쭉날쭉함(변동성)" 지표 44개 → 로지스틱 회귀
결과     : 위험군의 절반 이상(52.7%) 탐지, AUC 0.601, 구분 능력의 통계적 유의성 확인 (p=0.006)
핵심 발견: 활동량 "평균"보다 활동·수면 패턴의 "불규칙함"이 위험 신호
```

## 빠른 시작

```bash
pip install -r requirements.txt
# 데이터 준비: AI Hub에서 "치매 고위험군 웨어러블 라이프로그" 신청 후 raw_data/01_aihub_wearable/에 배치
python 소스코드.py                                     # 전체 분석 파이프라인 (전처리→모델→검증)
uvicorn service.main:app --host 127.0.0.1 --port 8002  # 웹 서비스 → http://127.0.0.1:8002
```

> **⚠ 데이터 안내:** AI Hub 원본 데이터와 그로부터 파생된 개인 단위 데이터는 이용약관상 재배포가 금지되어 이 저장소에 포함되어 있지 않습니다. [AI Hub](https://aihub.or.kr)에서 직접 신청 후 내려받아야 전체 파이프라인을 재현할 수 있습니다. 집계 결과(모델 성능 지표, 그래프)와 공공데이터(치매안심센터 현황)는 포함되어 있습니다.

## 프로젝트 특징

- **누수 없는 검증**: 피처 선택과 성능 평가의 데이터 분리, 50회 반복 교차검증, 순열 검정(p-value)까지 — 스스로 데이터 누수를 찾아 고치고 성능이 떨어지는 것을 감수한 과정을 [문서에 그대로 기록](guide/README.md#코드-리뷰-전처리--모델링--우리가-스스로-찾아-고친-것들)했습니다.
- **정직한 주장 범위**: "치매를 진단한다"가 아니라, 검증(Q4·Q5)이 허용하는 범위인 "위험군 스크리닝 후 전문기관 연계"까지만 주장합니다.
- **교체 가능한 파이프라인**: 더 큰 정식 데이터가 들어오면 데이터 파일만 갈아끼워 그대로 재학습·재검증할 수 있는 구조입니다.
- **상용화 데이터 루프**: 업로드 자동 적재(SQLite, 익명) → 검진 확진 라벨 연결 API → 라벨 데이터만으로 재학습·모델 교체까지 구현 — 서비스가 쓰일수록 학습 데이터가 쌓이는 구조입니다.
- **설명 가능한 판정**: 로지스틱 회귀 가중치로 각 지표가 위험 점수를 올렸는지/내렸는지 계산해, 결과 화면에서 지표별 양호/주의/위험 신호를 색상으로 보여줍니다.
